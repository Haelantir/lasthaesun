# Can I Use It With… — pairings to write.
#
#   npm run content:compat
#
# One pairing per line. The connective word (in / on / with / plugged into /
# washed in / dried in / stored in) is what makes it parse. Indent a line
# underneath to steer the ANGLE — never a verdict.
#
# Write "washed in a Dishwasher", not "in the Dishwasher". The parser has a
# specific `in the dishwasher` connective that swallows the target and leaves
# nothing after it, so that line is dropped and no page is written.
#
# If a batch fails on a source URL, name the dead domain in that pairing's notes
# before re-running. The writer reaches for the same host otherwise.
# Retail product pages and brand blogs are the repeat offender: they sit behind
# WAFs that refuse everything. Steer to manuals, standards and institutions.
# Confirmed blockers so far: cleaninginstitute.org, cdn.homedics.com.
#

Windex on a TV Screen
  화면 표면 코팅이 유리창과 무엇이 다른지가 축이다.
  암모니아·알코올 성분 세정제가 코팅에 무엇을 하는지, 제조사가 안내하는 방법,
  그리고 이미 한 번 닦아버린 경우에 무엇을 확인해야 하는지를 나눌 것.
  windex.com은 429로 막혀 검증에 실패했다. 다른 출처를 쓸 것.
  브랜드 제품 페이지와 업계협회 사이트는 대부분 차단되니 피할 것. 정부기관, 표준기관,
  대학 extension, 그리고 직접 열리는 제조사 매뉴얼을 우선한다.
